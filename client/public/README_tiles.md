Expected files:
- asphalt.png     (dark cracked road)
- concrete.png    (grey slab)

- sand.png        (tan desert)
- scrub_grass.png (dry patchy grass)
- rust_plate.png  (orange-brown corroded metal)
- neon_tile.png   (dark + cyan grid)

Served at: /assets/tiles/<name>.png

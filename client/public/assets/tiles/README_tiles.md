# Floor Tile Assets

Drop tile images here. Each should be ~128x128, seamless/tileable.
Format: JPG or PNG (both work; JPG is fine since these are opaque floor textures).

Expected files:
- asphalt.jpg      (dark cracked road, faded lane markings)
- concrete.jpg     (grey slab, cracks/stains)
- dirt.jpg         (brown unpaved, tire tracks)
- gravel.jpg       (dark grey flecked stones)
- sand.jpg         (tan desert sand)
- scrub_grass.jpg  (dry patchy wasteland grass)
- rust_plate.jpg   (orange-brown corroded metal)
- neon_tile.jpg    (dark + cyan neon grid)

Served at: /assets/tiles/<name>.jpg
